# StudentAcademicSystem.java
This is a student academic java system that has been implemented in a university to ensure that the university is able to capture student information, validate various functions such as validating the grading of students results, applying discounts and checking if students are at risk of failing and needing academic guidance and support.

Implementations:
Student validation- This captures all of the students names, age, mark, attendance and the category with which they belong in.
Age status- This is used to check if students are an adult or a minor by using the if else function.
Special Category- This uses the logical operator of "OR" to check if a student is between the ages of 18 and 60 to check if they are a special category student or not.
Academic Result System- This uses the if else structure to determine how a student passed and if they are qualifying for a distinction, a pass or a fail.
Admission and Exam Eligibility- This uses the if else structure and the logical operator "AND" with boolean data types to check if a student is eligible for a exams and if they meet the requirements for admissions.
Fee discounts and support of students- This checks if a student based on the special category is eligible for a 20% or a 5% discount while using a condition with the "AND" operators to check if a student needs academic support.
